🎯 What is nesterm?

🕹️ How to Play

Once nesterm is running, the controls are intuitive:

Movement: Arrow keys or WASD

Action Buttons (A/B): J/K or X/C keys

Start/Select: Enter and Shift key

Menu: Esc key

Save Game State: F2 (saves current progress)

Load Game State: F4 (loads last saved state)

Each game in nesterm is rendered in real-time using ASCII characters. Don't worry if it looks different from the original - that's the charm! The text-based graphics are surprisingly detailed and retain the original gameplay feel.

🛠️ Troubleshooting Tips

Issue: Game window doesn't open
Make sure you're using a compatible terminal. If Command Prompt doesn't work, try Windows Terminal or PowerShell.

Issue: Graphics look garbled
Some terminals have font settings that may affect ASCII art rendering. Try switching to a monospaced font like Consolas or Courier New.

Issue: Game runs slowly
Close other programs to free up resources, and ensure your terminal window isn't too large. Smaller window sizes often improve performance.

Issue: ROM files not showing
Double-check that your ROM files are in .nes format and placed in the correct folder. The folder should be the one you selected during setup.
